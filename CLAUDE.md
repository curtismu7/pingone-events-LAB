# pingone-events-lab

Demo-tier standalone app: a PingOne webhook receiver and events page, delivery health, and optional forwarding of each event to a configured Elasticsearch / OpenSearch. Re-implemented from the AI-DEMO2 PingOne events page (read-only source, never imported); scaffold copied from observability-LAB. Tier: Demo.

**Exception, owner-approved 2026-11-07:** this one app also runs on the SE cluster (Real, same image, hosted mode) so PingOne's cloud can reach the webhook. It is an exception to the "no hosted standalone apps" rule (2026-11-02) and to rulebook section 6 (mock-only SE build). The local Docker standalone (127.0.0.1:7802) stays as for every lab. Nothing is exposed from a laptop.

- Run: `./scripts/run.sh` (http://localhost:7802). Test: `npm test` (server `node --test test/*.test.js`, a glob; web vitest; scripts `node --test scripts/*.test.mjs`). Preflight `npm run doctor`. Reset `npm run reset`. Talk track `npm run talk-track`. Content pack `npm run content-pack`.
- Core: `server/src/eventParser.js` (Ping Activity -> one event shape; environment read off the actor; a top-level `type` only when there is no `action`), `receiver.js` (parse -> store -> answer, then `forward`, never awaited), `eventStore.js` (ring buffer, idempotent on eventId, atomic JSON file), `sinks/elasticsearch.js` (the ONE sink: bulk ndjson, eventId as `_id`, bounded queue, capped retries, scrubbed errors), `pingoneClient.js` (the Real pull: token POST + two GETs, never a write), `auth.js` + `config.js` (hosted fail-closed, constant-time Basic/header credentials), `netguard.js` (zero outbound; `setAllowed` follows the mode), `app.js` (routes), `eventsData.js` (story, labelled facts, setup text).
- Rules that bite: loopback bind only unless hosted; one port 7802; `POST /api/mode` is exactly `{ source: "mock"|"real" }`, 409 + reason when Real is unavailable; Mock allows NO outbound host; forwarding is OFF by default and Real needs `{enabled:true, confirm:true}`; the webhook answer never waits for the sink; hosted refuses to exist without a webhook credential and a separate page credential, and a value containing `REPLACE-ME` is refused; the receiver checks its credential BEFORE reading the body; other methods on the webhook paths are 405 (never the web page); no secret in any API response or log; only `.example`/`.invalid`/placeholder hosts in shipped text; nothing exposed from a laptop.
- Honesty rule: every product claim has a status (measured / inferred / UNVERIFIED). Forwarding to a real cluster, the Management API subscription shape and the SE deployment are UNVERIFIED. Do not upgrade one without reading the source again.
- Web: `web/src/App.jsx` (shell bar, tabs as nav links, Mock/Real toggle that reloads all data via `dataSignal`), `components/` Events, Delivery, Forward, Setup, DiagramTab + PatternDiagram. Colours from `tokens.css` and the shared stylesheet only. Event text renders as React text through `visible()`; never `dangerouslySetInnerHTML`.
- SE: `k8s/` (build only; deploy is the owner's). Placeholders `__IMAGE__`, `__SE_HOST__`, `__UI_HOST__`, `__CLUSTER_ISSUER__`; no namespace in manifests; `deploy.sh` needs `NAMESPACE` with no default, refuses `:latest`/`:HEAD`, and never applies the Secret.
